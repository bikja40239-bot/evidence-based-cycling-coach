# 训练决策与项目适配

## 先按经历与需求分层

不同FTP、性别和车型均可使用这个框架；课表剂量由近期实际耐受决定。

| 情境 | 起始决策 |
|---|---|
| 初次结构化训练、复训、生活负担大 | 先稳定可恢复的频次与耐力；可选少量质量刺激，必要时先不安排高强度 |
| 已有规律训练、质量课完成与恢复稳定 | 根据目标维持或递进工作时间；增加质量课前检查总负担 |
| 有经验的竞赛骑手 | 依赛历、专项弱项、训练阶段与恢复安排多个刺激；不因FTP高自动加课 |
| 持续疲劳、表现下降、睡眠不足或疼痛 | 减量、调整关键课或休息，检查供能／生活压力，必要时专业评估 |

对普通、初次结构化训练的健康成年人，约每周一堂可控质量课可作为实施选项，不是人人最低要求或最佳频次；一些人适合暂时零堂，有经验者可能耐受更多。两堂质量课之间通常安排轻松／休息日，但固定48小时不保证恢复。长骑、激烈团骑、比赛、下肢力量及高难技术课均计入负担。[T03]

多数骑行以较轻松强度为基础，质量课服务明确目标。极化、金字塔或其他分布按背景选择，不把80/20当唯一科学答案；说明按分钟还是课次计算，研究三分区不能与五／七分区同名替换。[T02]

## 先确定测量模式

**可靠功率＋可解释的FTP：**处方百分比来自已提供的当前基准，与体感和完成能力交叉判断。设备、校准／维护、测试方法、日期与环境用于解释测量，不是每次开课前逐项询问的清单；只有来源可疑或数据冲突影响本次建议时，核实对应缺口。短冲刺能力不能仅以FTP倍数概括，FTP也不能独自代表耐久、技术或比赛水平。

**没有可靠功率：**按时间、个人体感、说话能力与心率趋势执行。0–10 RPE中，0为完全休息、10为最大努力；轻松耐力通常约2–4且可完整交谈，5–6为更有意识的持续努力，7–8为很吃力但短工作段仍可受控。此处是沟通标尺，不与精确生理区一一对应。心率有滞后，短间歇不追目标心率。[D03]

模拟功率、模拟踏频不等于传感器实测；速度受坡度、风、路面、姿势与跟骑影响。设备负荷标签、单次最高心率和恢复数值不能独自确定阈值或恢复。[D01,D02]

## FTP与其他基准

- 需要可靠功率设备与熟悉的、安全可重复环境；不要求所有人先购买设备。
- 可采用规范20min计时、较长持续测试或设备标准协议。20min平均功率×0.95为常见估算，不是每个人准确的一小时能力或乳酸阈值。[T10]
- 记录完整协议，熟悉设备、散热和配速后测试；准备不足、明显疲劳／生病或不适合最大努力者先建立次最大基线。测试本身计入质量课。
- 若采用20min法，按同一完整协议执行热身与前置工作，记录该20min真实平均功率；不能用归一化功率或整次平均代替。阶梯估算也保留个体误差。
- 比较进步尽量固定设备、方法和环境，同时观察关键课完成、恢复与目标项目表现；不因一次高值就全面提高训练目标。
- 无功率者可重复舒适路线或固定时长任务，记录体感、心率趋势和条件；这可以追踪表现，不能把结果转换成精确FTP。

## 每堂课的组成

写明目的、总时长、热身、工作段与恢复、冷身、补给及调整条件。工作次数为n时，组间恢复通常计算n−1次；若另有每组后恢复需明确。加入所有段后重新求和。

质量课渐进热身约10–20min、结束轻松过渡约5–10min可作模板，按任务、天气和经验调整；不把分钟数当生理定律，不宣传冷身能保证消除酸痛或“排净乳酸”。安全停车优先于不停脚。[T06,T07]

## 训练组件：按目标选择

| 组件 | 用途及选择条件 |
|---|---|
| 舒适耐力 | 支持基础和目标耐久；用能恢复的时长，不强迫恒速；长时间低强度也可能是大负荷 |
| 持续中等／甜区／阈值附近 | 用于持续输出与配速；如采用88–92%FTP须说明这是实践标签，不能据此确定LT1／LT2 |
| 较长高强间歇 | 用强度与累计时间共同决定刺激；4×8研究不能证明人人应骑105–115%FTP或末组力竭。[T01] |
| 短间歇与反复变速 | 面向专项加速或高强耐受；短时能力差异大，选择可重复输出，不把百分比FTP当全部负担 |
| 冲刺 | 依比赛与技能需要选用，安排充分恢复和合适环境；不是所有人的FTP必修课。[T05] |
| 力量与核心 | 可补充下肢力量、躯干稳定、上肢控制；先学动作再加负荷，计入疲劳；不是必须每天做或必须练酸。[T04] |
| 技术 | 路线选择、制动、过弯、障碍与控车；按技能和场地选内容，训练质量优先于速度和疲劳量 |

以下只是**教练实施示例**，并非研究证明的统一最佳课表：

- 初次质量刺激可选：热身15min＋3×4min受控RPE约7＋两段4min轻松恢复＋冷身10min，共45min。若动作、配速或恢复不佳，减为2组或换轻松骑；不要求做到力竭。
- 已有可靠FTP且适合持续工作的骑手可选：热身10min＋2×10min、88–92%FTP＋组间5min轻松＋冷身10min，共45min。确认是适合目标的中高强负荷，不把它叫恢复骑。
- 长骑按近期稳定时长、目标预计用时和补给能力递进；不以100km作为跨公路／山地通用门槛。

不能因示例写在参考中就自动给每位使用者安排；只选与目标、耐受和可用时间相符的组件。

## 公路与山地的专项适配

| 项目 | 需求与安排重点 |
|---|---|
| 公路长途／爬坡／计时 | 持续输出、配速、姿势、疲劳下耐久与补给；按预计时长、爬升和目标强度安排 |
| 公路大组／团骑 | 在耐力基础上考虑反复加速、位置与协作技术；激烈团骑已是一项质量刺激 |
| XCO | 有氧与反复短高输出、陡坡、障碍与下降技术共同作用；不能仅用稳定阈值课代替专项。[M01] |
| XCM／山地长途 | 长时耐久、补给、地形变速与技术；同公里数公路与山地不等量，此项是专项需求判断 |
| 林道／休闲山地 | 按体验目标、路况、通过能力与舒适性安排，不默认竞技冲刺；推车和控车负担也考虑 |
| Enduro | 区分计时下坡、转场与整天累计负担；结合操控、力量和局部耐受，非只看FTP；属专项应用判断 |
| DH | 关注线路、制动、握持、上下肢吸收冲击与重复下降疲劳；踩踏少不等于恢复，心率不直接代表公路稳态代谢。[M02] |

山地日志补充路况、技术难度、累计下降趟数、前臂／握持疲劳和操控质量。新动作在注意力和控制较好时练，疲劳下技术训练是有条件的进阶选项。复杂下坡不边操作食物边追目标瓦数／心率；补给选安全位置。陡坡迫使高输出时，承认当天任务改变，可换平顺路面或骑行台完成可控耐力。

## 性别、年龄与生理阶段

不按性别统一减少课量或碳水，不因年龄偏大自动限制为轻骑；依个人功能、经历和反馈调整。成人、男性或竞技样本的剂量不能无条件外推所有人。

可自愿记录月经症状、睡眠、体感和表现，依个人影响调课；不按固定28天或排卵／经期标签机械安排强度。相关研究平均效应很小且证据质量有限，也不否定个体症状。[G01]

未成年人、孕产期、慢病、重要用药、疑似REDs或进食障碍者采用对应专业依据；通用原则可继续讨论，高强度、极限测试、热量缺口或补剂剂量不直接套成人模板。[N06,G02]

## 递进、减量与漏课

近期任务稳定完成、动作／配速受控、后续疲劳可接受时，主要增加一个变量；不机械每周加10%。需要调整时先删去不重要的负荷，而不是增加补剂顶住。

恢复窗口按数次疲劳、睡眠、疼痛、表现和生活压力安排。赛前taper研究不等于人人必须练三周减一周，比赛减量与日常恢复周要区分。[T03,T09]

漏课后按剩余时间、恢复与目标重排：不补齐所有课，不为重启六天循环堆积质量课，亦不无视下一堂是否适合当前状态。若必须取舍，保留最服务阶段目标、且能恢复的刺激。

## 复盘

以下是日志可选字段，使用与本次判断有关的已有资料，不要求每次补齐；缺口提问仍遵循入口的最少提问规则。

记录日期、项目／路况、实际时长、主组完成、整堂RPE、补给、睡眠、疼痛和次日状态。整堂RPE描述整个任务，固定记录方式，不用末组或最难一段的体感替代。[T11] 有实测功率时再加工作段平均功率、衰减和可用的心率趋势。心率漂移需在输出与条件相对稳定的任务中解释，不能从整次均速／均心率直接算。

改善可表现为同任务更从容、稳定完成更多工作、目标项目表现改善及恢复可接受；不只追FTP数字。对数据冲突先检查设备、条件、疲劳和测量方法，再判断训练变化。
