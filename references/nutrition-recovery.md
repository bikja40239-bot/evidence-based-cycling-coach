# 营养、补给与恢复决策

以下范围主要来自健康成人运动人群，是按情境选择的参考，不是所有骑手必须达到的摄入下限。不同性别、FTP和车型都按当前任务相关的负荷、耐受与恢复需求调整；不预存个人体重或菜单。下列变量用于决策，不是开口前必须收齐的资料：骑中补给通常可按g/h直接安排，日常范围可先用g/kg/day，不为这些问题默认追问体重或饮食方式。体重趋势用于确有需要的体重管理／供能复核。

## 先保障总能量与食物质量

规律进餐、足够能量、按训练供碳水、每日蛋白、饮食多样性与睡眠优先。包括足够脂肪和微量营养素，不以高蛋白挤占训练燃料，不默认增重或减脂。手表热量是估算，不能精确吃回或直接据此制造热量缺口。[N01,N06]

g/kg表示营养素克数除以体重，不是食物重量。制作具体食谱或核算时写清生重／熟重、可食部与所用标签；普通饮食原则不必追问品牌、烹饪或外卖习惯。胶、运动饮料、奶、水果和零食计入全天总量，不重复加算。无法确定总能耗时给可反馈范围，不伪造精确维持热量。

## 日碳水：按日总量和相邻课表选择

| 负荷情境 | 参考g/kg/day |
|---|---:|
| 低强度、轻量活动／部分休息日 | 3–5 |
| 中等训练，约1h/day | 5–7 |
| 较大耐力负荷，约1–3h/day中高强度 | 6–10 |
| 极高负荷，约超过4–5h/day中高强度 | 8–12 |

来自联合立场文件[N01]，这些时长与区间有重叠，不能当机械分档算法。结合全天活动、强度、前一日消耗、下一次关键课、食欲和身体反应选择；一堂短间歇不自动对应8–12。休息日也可能需要补回长骑消耗或准备次日比赛。

关键训练前中后充足供能有价值，但不要求全天多数碳水挤在这些时段。长课／比赛前可依据进食间隔、耐受与任务考虑运动前1–4h约1–4g/kg碳水；这是情境范围，不要求每次短骑吃到上限。[N01]

## 骑行中：先算克数，再选食品和携带方式

| 运动情境 | 参考碳水摄入 |
|---|---|
| 少于45min | 通常无需专门补碳水；供能不足或临近其他训练时另判断 |
| 45–75min持续高强度 | 可小量摄入或碳水口腔接触，不等于所有轻松短骑都要用胶 |
| 约1–2.5h耐力活动 | 通常30–60g/h，依强度、骑前进食和耐受调整 |
| 超过约2.5–3h、供能要求高 | 可渐进至60–90g/h；多转运碳水并练习胃肠耐受 |

依据[N02]。这些范围不是最高摄入纪录竞赛；没有练习过的骑手不突然套90g/h。高于90g/h不是通用默认，需要明确长时／高耗任务、个体适应和相应证据。

饮料mL不等于碳水g，每包胶也不等量。计算`各份碳水合计÷训练小时`，检查携带、取水和胃肠舒适。葡萄糖／麦芽糊精加果糖可用于较高摄入率，不固定某商业品牌。山地技术段提前规划安全补给点，不能为吃胶分散控车注意力。

## 训练后：区分恢复窗口

若两次耗糖任务间隔短于约8h、需要快速恢复，可尽早按约1.0–1.2g/kg/**h**在前4h补碳水，再回到全天目标；这是小时摄入率，不是每次骑后固定喝一次大剂量。[N01]

普通一日一练或下一次训练较远时，及时正常餐和全天足量往往更实用，不必强行追狭窄窗口。训练后在餐／加餐提供高质量蛋白；约0.3g/kg可作为便于安排的选择，不必是蛋白粉。[N03,N04]

## 蛋白：训练日和恢复日都覆盖

联合指南常用1.2–2.0g/kg/day，ISSN常用1.4–2.0；按训练、总能量、食物偏好和相关健康背景选择，不写“人人至少2.2”。能量限制、增肌或某些人群可能需要调整，但不能据此自动给所有人高剂量。[N01,N03]

每天分布于数次进餐，约0.25–0.4g/kg/次、相隔约3–4h可作为安排参考；全天足量比精确卡分钟更重要。恢复日继续支持修复，不常规降到1g/kg。乳清等是便捷食品选项，不是必须额外叠加的刺激。[N03,N04]

## 补水与钠

结合口渴、环境、强度、汗损、取水和胃肠舒适制定，不给所有人统一每小时500或1000mL。需要更具体方案时，在相似条件下重复估算：

`汗率L/h≈(骑前kg−骑后kg＋饮入L−排尿L)÷时长h`

同秤、相似衣着、尽量干身；长骑底物和呼吸损失影响精度。一次测量不是全年固定剂量。避免因过量饮水造成体重增加；补盐不能抵消过量饮水风险。[N05]

长时、炎热、大量或高钠汗时结合食物与饮料的钠制定方案。若提供mg/h或mg/L，写明假设与调整依据；钠mg与食盐g不可混用（1g食盐约含393mg钠）。电解质不能保证防止所有抽筋。心肾疾病及影响水盐平衡的用药者按专业建议调整。

## 能量可用性、减脂与不同人群

REDs可影响不同性别，稳定体重和较高BMI都不能排除供能不足。持续疲劳、表现下降、反复生病／骨应力伤、非计划体重下降、月经或男性性功能变化，触发供能和负荷复核，必要时专业评估；不以单一能量可用性数字远程确诊。[N06]

不把月经异常当训练成效，也不把所有异常归因于REDs；需鉴别其他原因。依个人症状与记录调整，不机械周期同步。激素避孕、围绝经期、孕产／哺乳背景不能套用自然规律月经样本结论。[G01,G02]

减脂只在明确目标且适合时讨论，以可维持的小幅调整和反馈为主，保护关键课供能与恢复；不自动要求先增重再减脂、越轻越好或同时快速减重与大幅加量。未成年人／生长、孕产、慢病和进食障碍相关情境，不直接套成人缺口或补剂方案。

## 补剂：按用途决策

先检查训练、食物、供能与睡眠，再判断目标、证据、耐受、费用和产品质量；先在训练试用。比赛使用考虑可靠批次第三方检测，降低污染不确定性。AIS分组会更新，实施时按需复核；A组不表示人人必需。[N07,N08,N12]

| 补剂／食品 | 可考虑的用途 | 条件与限制 |
|---|---|---|
| 咖啡因 | 特定耐力／竞技表现 | 成人低剂量约2–3mg/kg可有效；按耐受选择，计入咖啡等全部来源，避免破坏睡眠；不默认从高剂量开始，未成年人／孕产／相关疾病用药另评估。[N09] |
| 肌酸单水合物 | 力量、短高强和反复冲刺目标 | 不承诺提高FTP或稳态耐力；体重变化可能影响项目取舍。[N10] |
| 硝酸盐／甜菜根 | 特定耐力任务可试用 | 效果因水平和个体而异；标签看硝酸盐含量，不是甜菜根粉重量，不建议自行配制化学硝酸盐／亚硝酸盐。[N11] |
| β-丙氨酸 | 某些持续高强任务 | 需持续补充，非临时一吃；不能把机制直接等同FTP收益，注意刺痒和耐受。[N07,N08] |
| 蛋白粉 | 普通饮食难满足蛋白时 | 计入全天目标，非人人每次必喝。[N03] |
| 维生素／矿物质，尤其铁 | 有缺乏风险或明确需要 | 按饮食、必要检验和专业建议处理；男性也可能缺铁，女性也不自动需铁剂，疲劳本身不足以诊断。[N06,N08,G02] |
| 鱼油、姜黄素 | 特定需求下个别讨论 | AIS目前为B组，不能由酸痛／标志物变化直接承诺竞技收益，不常规开统一剂量。[N12] |
| 谷氨酰胺 | 不作为常规骑行表现／恢复必需品 | 汇总证据未支持稳定的有氧、免疫或体成分增益；医疗用途另论。[N13] |
| CoQ10 | 不作为常规涨功率必需品 | 较新汇总显示运动表现效应有限且不一致，血浓度上升不等于有效。[N14] |

讨论具体剂量时核验当前证据与健康／用药背景；不将上述表改写为所有骑手的购买清单。

## 睡眠与恢复安排

健康成人通常以每晚7–9h为参考，训练者需求可更高，应结合睡眠机会、白天困倦和训练反应。保持规律作息；午睡是可选补充，不能用它长期替代不足夜眠。截图的线性睡眠公式不是通用已验证规则。[T08]

日常恢复优先供能、蛋白、补水、睡眠与合理负荷。按摩、泡沫轴等按舒适需求选，不作为保证适应的必要程序，也不靠消除所有酸痛评定恢复。

## 计算与交付检查

1. 选择符合任务的范围；需要且已有体重时再换算，无体重可保留g/kg，不把补齐个人资料作为普通建议的前提，不预置任何个人数值。
2. 明确每小时、每天或每次，蛋白与碳水是营养素g；液体mL、钠mg与食盐g分别处理。
3. 食谱与骑中补给加总，避免重复计量；总能量与饮食脂肪／多样性也核对。
4. 说明安全可执行的携带和进食位置、胃肠不适时的调整以及下次反馈内容。
