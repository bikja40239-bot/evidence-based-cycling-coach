## 饮食、力量与恢复原思路

截图包含：渐进热身10–20min、冷身10min；睡眠用“7h底数＋每日训练时长×0.5”估算，可午睡；训练前中后重视碳水；骑前胶和500mL电解质饮料、每小时两胶和600mL饮料的例子；训练后1.2g/kg碳水及至少0.3g/kg蛋白；训练日碳水6–8、高强日8–12g/kg，蛋白至少1.6–2.2g/kg；非训练日碳水3–5、蛋白1g/kg。

原文还列肌酸、咖啡因、β-丙氨酸、甜菜根、蛋白粉、维生素矿物质尤其铁、鱼油、姜黄素、谷氨酰胺、CoQ10的“重要性”顺序；建议每周一次并非只有冲刺的健身房训练、核心抗扭转和骑前臀肌激活。末尾强调供能与恢复，提出体重可先略增再减脂的个人思路。品牌及单包45g碳水只是例子，不构成产品推荐。

## 保留与调整

| 方法 | 本技能处理 |
|---|---|
| 状态好时做质量课、按反馈调整 | 保留，结合近期负荷与生活压力 |
| 长间歇＋甜区／阈值＋耐力＋休息 | 保留组件；按目标与耐受选用，不要求人人同周全做 |
| 4×8、105–115%FTP | 作为博主处方；T01没有验证统一百分比，无功率改用受控、可重复努力 |
| 无功率尽力、末组全力 | 改为整堂能稳定完成，不默认力竭 |
| 百公里 | 改为适合近期耐受的时长与地形；山地同距离负荷可完全不同 |
| 间歇永远优先、断课从头 | 按阶段目标与恢复重排，不追补、不机械重启 |
| 充分供能、骑中补糖 | 保留方向，按时长、强度、恢复窗口与胃肠耐受给量 |
| 高强日固定8–12g/kg碳水 | 限定为极高日训练量的参考，不按单堂强度自动选择 |
| 休息日蛋白1g/kg | 改为恢复日继续足量蛋白 |
| 每次结束固定快速补糖 | 区分短恢复窗口与普通一日一练 |
| 补剂通用排名 | 改为用途、证据、人群、耐受与质量决策 |
| 核心、力量、臀肌激活 | 保留可选组件，不把某动作或每日练核心设为普遍必要 |
| 睡眠公式、先增后减 | 记录为个人经验，实际按个体需要处理 |

证据与局限见 [evidence.md](evidence.md)。改编方案称“受其方法启发的适配”，不称博主亲自设计或完整研究验证。
